# ⭐ Product Review Analysis

**Product Review Analysis** is a web-based application designed to analyze customer reviews and understand opinions about products. The system helps identify positive, negative, and neutral reviews, extract important keywords, and visualize customer satisfaction to support better business decisions.

## 🚀 Features

- 📝 Add and analyze product reviews
- 😊 Classify reviews as positive, negative, or neutral
- ⭐ Display product ratings
- 🔍 Extract important keywords
- 📊 Visualize customer feedback using charts
- 📈 Calculate overall customer satisfaction
- 🔎 Search and filter reviews
- 💾 Store and manage review records

## 🛠️ Technologies Used

- **HTML5** – Webpage structure
- **CSS3** – Styling and responsive design
- **JavaScript** – Application logic
- **Chart.js** – Data visualization
- **LocalStorage** – Store review data in the browser

## ⚙️ How It Works

1. Users enter product reviews and ratings.
2. The application processes the review text.
3. Sentiment analysis classifies the reviews.
4. Important keywords and customer opinions are identified.
5. Results are displayed through statistics, charts, and reports.

## 🎯 Objective

The main objective of this project is to help businesses understand customer opinions, identify product strengths and weaknesses, and improve product quality and customer satisfaction.
